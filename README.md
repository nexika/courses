# Nexika courses

Verified courses for [Nexika](https://github.com/nexika/nexika)'s tutor, **prof**.

Every lesson here has to prove itself: its code runs, every claim its text makes is checked
against what the code produces, every fact cites and quotes a primary source, every exercise
fails on the starter and passes on the solution, and real learners pass it. Each lesson shows
honestly how far it got.

**First course (in progress):** AI Engineering with Claude Code, from complete beginners to
working engineers moving into AI.

*Status: foundations being built. Nothing here is ready for learners yet.*
